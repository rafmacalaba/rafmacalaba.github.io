Armada is an open-source orchestration tool that structures multi-agent coding work as phased contracts — each phase gated by verifiable evidence before the next begins. It dispatches specialist agents (backend, frontend, QA, security, adversary) into isolated voyage lanes, collects their output receipts, and tracks defects through ledgers. The system enforces role boundaries, parallelizes independent work, and surfaces ambiguous requirements for human adjudication before code is written. It was built to replace ad-hoc agent chaining with a repeatable delivery process that produces auditable artifacts at every step.
